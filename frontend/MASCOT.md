# Маскот «Уми»

Интерактивный маскот Уми встроен без дополнительных runtime-зависимостей: визуал — SVG + CSS-анимации, состояние — Redux Toolkit.

## Где используется

- Вход и регистрация: указывает на основную кнопку, думает во время запроса, радуется успеху и расстраивается при ошибке.
- Лента обменов, «Мои вещи» и «Мои цепочки»: скучает и перемещается по пустой области; при переходе на непустую вкладку сразу возвращается в обычное состояние, а при появлении новой цепочки радуется.
- Уведомления: подбегает к колокольчику при новом ID, а после открытия занимает отдельное место внутри панели и не перекрывается ею.
- Профиль: читает новый отзыв; один постоянный экземпляр плавно перемещается между безопасными зонами строк заблокированных пользователей при наведении или фокусе, не сдвигая аватар и данные от левого края. В злой мимике глаза подняты и визуально отделены от рта.
- Формы профиля и вещей: реагирует на отправку, успешный ответ и ошибку.
- Чаты обмена, поддержки и админской поддержки работают без Уми и без его подсказок. Enter отправляет сообщение, Shift+Enter добавляет новую строку; после отправки поле остаётся в фокусе. Рабочие области поддержки имеют ограниченную высоту, длинная переписка прокручивается внутри списка сообщений, а при отправке и получении чат плавно переходит к последнему сообщению.
- Новые пользователи: после успешной регистрации переходят в «Обмены» и проходят знакомство из семи шагов. Прогресс сохраняется отдельно для ID пользователя.

Глобальный проводник не монтируется на лендинге, в поддержке, в админке и на странице конкретного обмена, поэтому он не появляется поверх чатов. На остальных страницах проводник ищет свободное место с учётом текста, элементов управления и карточек. Видимые перемещения выполняются только по безопасному пути; если такого пути нет, Уми остаётся на месте, а если место стало занято — скрывается.

Форма рта выбирается в JSX через SVG-атрибут `d` по текущему `mood`, без CSS `d: path(...)`, поэтому мимика одинаково работает в Firefox, Chrome и Safari.

## Состояния

`idle`, `hello`, `listening`, `thinking`, `hint`, `pointing`, `happy`, `excited`, `celebrate`, `concerned`, `sad`, `bored`, `reading`, `angry`.

Режимы показа: `ambient`, `attention`, `dialog`.

Перемещения: `roam`, `approach`, `wander`, `run`, `scan`, `kick`.

## Основные файлы

- `src/Components/UI/Mascot/Mascot.tsx` — SVG-персонаж.
- `src/Components/UI/Mascot/Styles.module.scss` — анимации и адаптив.
- `src/Components/UI/MascotGuide/MascotGuide.tsx` — позиционирование рядом с DOM-целями и перемещение по экрану.
- `src/Components/UI/MascotGuide/Styles.module.scss` — реальное перемещение проводника по координатам экрана.
- `src/Features/Mascot/mascot.types.ts` — типы состояний/событий.
- `src/Features/Mascot/mascotEvents.ts` — карта событие → реакция.
- `src/Features/Mascot/mascotSlice.ts` — Redux-состояние.
- `src/Features/Mascot/mascotVisibility.ts` — запрет глобального проводника на исключённых маршрутах.
- `src/Hooks/useMascot.ts` — публичный API для компонентов.
- `src/Components/UI/OnboardingTutorial/OnboardingTutorial.tsx` — подсветка элементов и управление шагами знакомства.
- `src/Features/Tutorial/` — шаги, сохранение прогресса и Redux-состояние туториала.

## Как вызвать реакцию

```ts
const { reactTo } = useMascot();
reactTo("FORM_ERROR");
```

Чтобы изменить поведение продукта, достаточно поменять реакцию в `mascotEvents.ts`; страницы не должны напрямую выбирать CSS-анимацию.

## Проверка

```bash
npm ci
npm run check
npm run dev
```

`node_modules` не следует включать в итоговый архив: зависимости устанавливаются на целевой машине через lock-файл. Это также гарантирует установку нативной сборки Rolldown для нужной операционной системы.
