# AI-антискам в чатах обмена

Каждое пользовательское сообщение ставится в очередь `antiscam_analyses` в той же
транзакции, в которой сохраняется чат. HTTP-ответ не ждёт модель: проверку выполняет
один фоновый worker, рассчитанный на лимит Ollama `OLLAMA_NUM_PARALLEL=1`.

Проверка гибридная:

- строгие правила сразу находят SMS-коды, данные карт, внешние ссылки и оплату вне сервиса;
- локальная модель получает проверяемую реплику и пять предыдущих сообщений;
- критический сигнал правил нельзя отменить ответом модели;
- после пяти ошибок модели проверка завершается по правилам, а не теряется;
- несколько сигналов одного пользователя в одном обмене объединяются в одну карточку.

Модель ничего не блокирует и не удаляет. Администратор открывает раздел
«AI-антискам», видит причину, риск и всю переписку, после чего подтверждает нарушение
или отмечает ложное срабатывание. Пользователю результат проверки не показывается.

## Локальная проверка

```bash
make db
make llm
make run
```

Отправьте в чат обмена, например: `Пришли код из SMS для подтверждения`. Через несколько
секунд карточка появится в `/admin?section=antiscam`. Без `OLLAMA_URL` строгие правила
продолжают работать, поэтому API и базовая защита не зависят от состояния модели.
