# Статистика админской панели

Главная страница админки получает сводные данные одним запросом:

```http
GET /admin/dashboard
```

Ручка доступна только авторизованному администратору. Сначала middleware проверяет
JWT-cookie `access_token`, затем читает актуальный признак `is_admin` из базы данных.

Пример ответа:

```json
{
  "users_total": 12,
  "pickup_points_total": 3,
  "items": {
    "total": 24,
    "available": 15,
    "reserved": 3,
    "traded": 5,
    "withdrawn": 1
  },
  "exchanges": {
    "total": 9,
    "proposed": 3,
    "confirmed": 2,
    "completed": 3,
    "cancelled": 1
  }
}
```

Все значения вычисляются одним SQL-запросом. Если таблицы пустые, каждый счётчик
равен нулю. Отдельная таблица и новая миграция для дашборда не нужны: статистика
не хранится и поэтому всегда отражает текущее состояние данных.
