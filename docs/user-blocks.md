# Блокировка пользователей

Блокировка нужна, чтобы два пользователя больше не попадали в один новый обмен. Она
направленная: Алиса может заблокировать Боба, даже если Боб не блокировал Алису. Для
поиска этого достаточно — DFS считает такую пару несовместимой в обе стороны.

## API

Все маршруты требуют авторизацию через cookie `access_token`.

| Метод и путь | Что делает | Успешный ответ |
|---|---|---|
| `GET /users/me/blocks` | Возвращает личный список блокировок | `200 OK` и массив |
| `POST /users/me/blocks/{user_id}` | Блокирует пользователя | `204 No Content` |
| `DELETE /users/me/blocks/{user_id}` | Удаляет блокировку | `204 No Content` |

Повторная блокировка и повторная разблокировка безопасны. Заблокировать самого себя
нельзя — API вернёт `400 Bad Request`. Неизвестный `user_id` при блокировке даёт
`404 Not Found`.

Заблокированный пользователь не получает уведомление и не видит, кто его заблокировал.
Список доступен только владельцу блокировок.

## Влияние на обмены

При блокировке система:

1. сохраняет связь в `user_blocks`;
2. отменяет общие обмены этих пользователей, которые ещё находятся в состоянии
   `proposed`;
3. не меняет `confirmed`, `completed` и уже отменённые обмены.

Сохранение блокировки и отмена предложений выполняются одним SQL-выражением. Поэтому не
возникает состояния, в котором предложение отменилось, а блокировка не сохранилась, или
наоборот.

## Влияние на DFS

Перед добавлением кандидата DFS сравнивает его владельца со всеми владельцами в текущем
пути. Кандидат пропускается, если существует блокировка в любом направлении хотя бы с
одним участником.

Блокировка не останавливает поиск полностью. После пропуска нежелательного кандидата DFS
продолжает обход и может найти обмен с другими пользователями. После разблокировки пара
снова может участвовать в будущих поисках.

## Основные файлы

| Файл | Назначение |
|---|---|
| `migrations/00005_user_blocks.sql` | таблица блокировок и индексы |
| `queries/user_blocks.sql` | добавить, получить и удалить блокировки |
| `queries/exchange_search.sql` | проверка блокировки текущего пути DFS |
| `internal/user` | HTTP API и бизнес-логика списка блокировок |
| `internal/exchange/service/service.go` | исключение заблокированных кандидатов из DFS |
