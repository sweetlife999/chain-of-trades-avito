# Активные обмены пользователя для администратора

Администратор может посмотреть, в каких незавершённых обменах участвует конкретный
пользователь:

```text
GET /admin/users/{user_id}/exchanges?limit=20&offset=0
```

Ручка возвращает только обмены в статусах `proposed` и `confirmed`. Завершённые и
отменённые обмены в этот список не входят.

В каждом обмене возвращаются его статус и даты, все участники, отдаваемые и получаемые
вещи, а также решение каждого участника. Ответ содержит объект `pagination` с полями
`limit`, `offset` и `total`.

Сначала middleware проверяет JWT-cookie `access_token`, затем читает актуальное поле
`users.is_admin` из базы данных. Поэтому без входа сервер отвечает `401`, обычному
пользователю — `403`, а для неизвестного `user_id` — `404`.
